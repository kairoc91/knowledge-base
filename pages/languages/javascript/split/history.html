Javascript

Atualizado em 4 de novembro de 2026.

A lingugem Javascript surgiu da necessidade de melhorar a interação do usuário com as páginas de um site. Ela foi desenvolvida por Brendan Eich em 1995, inspirada na linguagem Java.

A Netscape, que na época desenvolvia o navegador Netscape junto com Brendan submeterem a linguagem para um organização de padronização, atualmente TC39, composta por diversos colaboradores, e eles são responsáveis por definir esses padrões do Javascript, que por fim é adotado pelos principais navegadores como Chrome e Firefox.

A especificação da linguagem é chamada de ECMAScript, e o nome comercial da lingugem permaneceu Javascript, além de suas especificações próprias, ela é capaz de utilizar as API do browser que permitem implementar um comportamento dinâmico para as informações expressas no HTML da página, e o próprio browser lê o ECMAScript e compila para machine code.
