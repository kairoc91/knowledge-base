Dominando o Operador de Coalescência Nula (??) no JavaScript

Resumo: Descubra de forma simples e sem complicações como usar o operador ?? para definir valores padrão no seu código sem apagar dados válidos como o número zero.

1. O que é isso na prática? (Sem Tecniquês)

O Operador de Coalescência Nula — representado por dois sinais de interrogação seguidos (??) — é um recurso do JavaScript usado para definir um valor de reserva (um "plano B").

Em palavras bem simples: ele olha para a informação do lado esquerdo. Se essa informação estiver completamente vazia ou ausente, ele ignora a esquerda e escolhe o valor da direita. Se a informação da esquerda existir, ele fica com a esquerda e nem olha para a direita.

Nota linguística: De acordo com o Dício, coalescência significa "fusão, união, junção ou aderência do que estava separado".

2. A Analogia do Mundo Real

Imagine que você vai a uma lanchonete e pede um suco de laranja.

  • Se o garçom trouxer o suco de laranja que você pediu, você bebe o suco.
  • Se o garçom avisar que o suco está em falta (ou seja, null, que significa "vazio intencional"), você aceita a opção padrão da casa: água.
  • Se o garçom nem souber o que colocar no copo porque ninguém anotou o pedido (ou seja, undefined, que significa "não definido"), você também aceita a água.

Agora, se você pedir um suco sem açúcar (com zero gramas de açúcar, o número 0), o açúcar é zero, mas o suco existe! Você não quer que o garçom troque seu suco por água só porque você pediu zero açúcar. O operador ?? entende exatamente isso: ele só aciona a água se o copo estiver realmente sem suco nenhum (null ou undefined).

3. Qual problema isso resolve?

Antigamente, para definir um valor padrão, os programadores usavam o operador || (conhecido como "OU lógico"). O problema é que o || trata vários valores válidos como se fossem erros ou ausência de dados.

No JavaScript, o operador || descarta qualquer valor considerado falsy (valores que a linguagem interpreta como falsos), como:

  • 0 (o número zero)
  • "" (um texto/string vazio)
  • false (o valor booleano, que significa falso)

Se um usuário configurasse o volume de um jogo para 0 (som desligado), o antigo || entendia que 0 era "falso" e forçava o volume padrão para 50! O operador ?? foi inventado justamente para resolver essa falha: ele respeita o 0, o "" e o false, acionando o plano B apenas quando o dado for null ou undefined.

4. Quebrando a Abstração (Anatomia do Código)

Veja a estrutura básica de uma instrução usando o operador ??:

let resultado = valorPrincipal ?? valorPadrao;

Dissecando cada pedaço dessa instrução:

let
Palavra reservada do JavaScript usada para criar uma variável (uma "caixinha" na memória do computador que guarda um dado).
resultado
O nome que escolhemos para a nossa variável que vai guardar a resposta final.
=
O sinal de atribuição. Ele pega o resultado do lado direito e o guarda dentro da caixinha da esquerda.
valorPrincipal
O dado de entrada que queremos testar primeiro (a nossa prioridade).
??
O Operador de Coalescência Nula. Ele testa se o valorPrincipal é null (ausente) ou undefined (não definido).
valorPadrao
O valor de reserva (nosso "plano B") que só será usado se a prioridade for nula ou não definida.
;
O ponto e vírgula, que indica ao computador o fim da instrução.

5. Exemplo Prático Comentado

Abaixo está um código simples simulando a configuração de preferências em um aplicativo de leitura de livros digitais:

// Criamos uma variável para guardar o tamanho da fonte.
// O usuário escolheu o tamanho 0 (modo compacto especial).
let tamanhoFonteUsuario = 0;

// Definimos o tamanho final usando o operador ??
// Como 0 NÃO é null nem undefined, o valor 0 será mantido!
let tamanhoFinal = tamanhoFonteUsuario ?? 16;

// Exibimos a mensagem no console (a tela de testes do programador)
console.log(tamanhoFinal); // O resultado impresso será: 0

Se mudarmos a primeira linha para let tamanhoFonteUsuario = null;, o código vai identificar a ausência de valor e o tamanhoFinal passará a ser 16.

6. Cuidado com a Pegadinha (Erros Comuns)

Pegadinha 1: Confundir || com ?? ao lidar com textos vazios ou o número zero

O erro mais comum de quem está começando é usar o || quando se quer aceitar respostas como 0 ou "" (texto sem caracteres).

let nomeDigitado = ""; // O usuário limpou o campo de texto

// ❌ Jeito errado (ou confuso) com ||
// O || acha que "" é inválido e substitui pelo nome padrão!
let nome1 = nomeDigitado || "Visitante"; 
console.log(nome1); // Imprime: "Visitante" (Incorreto se o texto vazio era intencional)

// ✅ Jeito certo com ??
// O ?? percebe que "" é um texto real e mantém o texto vazio!
let nome2 = nomeDigitado ?? "Visitante";
console.log(nome2); // Imprime: ""

Pegadinha 2: Tentar misturar ?? com && ou || sem usar parênteses

O JavaScript proíbe misturar o ?? diretamente com outros operadores lógicos (&& ou ||) na mesma linha sem indicar a ordem com parênteses.

// ❌ Jeito errado (Gera um erro de sintaxe e o programa não roda)
let opcao = valorA || valorB ?? "padrão";

// ✅ Jeito certo (Usando parênteses para isolar a primeira comparação)
let opcao = (valorA || valorB) ?? "padrão";

7. Resumo de Bolso (TL;DR)

  • Foco estrito: O operador ?? aciona o valor padrão apenas quando o dado for null (nulo) ou undefined (não definido).
  • Preserva dados reais: Diferente do operador ||, o ?? preserva valores como 0, "" e false.
  • Sintaxe limpa: Ele deixa seu código mais seguro e legível na hora de preencher dados ausentes em configurações e formulários.
